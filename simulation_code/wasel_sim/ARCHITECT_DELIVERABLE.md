# Wasel Simulation Architect Deliverable

This folder implements the simulation system described in the Wasel market simulation specification:

- assumptions registry loaded from YAML
- driver cohort onboarding and churn transitions
- rider demand and churn corrections
- supply-demand matching layer to validate trip assumptions
- monthly financial model and cash tracking
- deterministic scenario runner
- sensitivity analysis
- Monte Carlo analysis
- reporting artifacts
